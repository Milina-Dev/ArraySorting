# Сортировка массива

## Описание программы

Программа предназначена для сортировки массива из 10 целых чисел по возрастанию.

Пользователь может выбрать один из двух способов заполнения массива:

Автоматическое заполнение случайными числами от 1 до 100.

Ручной ввод 10 чисел с клавиатуры.

После заполнения программа выводит исходный массив, сортирует его по возрастанию, а затем выводит отсортированный массив и количество итераций.

## Алгоритм сортировки

В программе используется сортировка пузырьком (Bubble Sort).

Принцип работы алгоритма:

- Программа сравнивает два соседних элемента массива.

- Если левый элемент больше правого, они меняются местами.

- После каждого прохода наибольший из оставшихся элементов перемещается в конец массива.

Проходы повторяются, пока массив не будет отсортирован по возрастанию.

## Подсчёт итераций

Количество итераций считается по количеству сравнений соседних элементов массива во время сортировки.

Каждое сравнение увеличивает счётчик на единицу, независимо от того, произошёл обмен элементов или нет.

Для массива из 10 элементов в данной реализации выполняется 45 сравнений.
